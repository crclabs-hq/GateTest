How is this decided?
The headline takes the worst state on the gate path (worker, queue, git-host deliveries, engine, deployed build):
  1. any gate-path read failed: Cannot confirm the gate
  2. any gate-path signal cannot tell: Cannot tell whether the gate is running
  3. worker stalled or deliveries failing: Gate is not running
  4. running with blockers open: Gate running · N merges blocked
  5. only when all of the above are clear and every panel reads: Gate held, the one place the pass mark appears.
